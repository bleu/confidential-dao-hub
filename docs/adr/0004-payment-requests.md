# Payment requests include reimbursements

Priority: **todo**. App status: **Soon**. Use Payment Request for a recipient's request that a DAO pay them; reimbursements, invoices, and contractor payments fit this feature. A reimbursement specifically repays an expense already incurred on the DAO's behalf. This vocabulary avoids restricting the feature to expense repayment.

Use independent feature contracts. Before implementation, settle who may request and approve, rejection/cancellation rules, duplicate payment prevention, supported assets, funding, and evidence storage. Specify which request fields and amounts are confidential, who may decrypt them, and what approval/payment metadata remains public. No payment-request contract or evidence-storage system is implemented yet.
