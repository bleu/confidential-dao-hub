# Confidential employee payroll

Priority: **todo**. App status: **Soon**. Payroll covers DAO-initiated employee payments and is distinct from recipient-initiated Payment Requests. It will own an independent contract boundary rather than reuse the buyback vault.

Before implementation, decide supported assets, one-off versus recurring payments, batching limits, funding/reserves, who authorizes a run, retries, and employee changes. Define which administrators and recipients can decrypt amounts, which metadata is public, and whether any aggregates are disclosed. No automatic public salary disclosure is assumed. No payroll contract is implemented yet.
